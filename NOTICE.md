# Aviso sobre firmware y software propietario

Este repositorio **no distribuye** imágenes de firmware, bootloaders, módems, blobs propietarios de Motorola/Qualcomm ni el sistema stock completo.

Los scripts esperan que el usuario aporte su propio backup del dispositivo o una copia del firmware stock obtenida legalmente. Las rutas por defecto apuntan a `/workspace/Android/cypfq_backup`, que no forma parte del repositorio.

BoomingMusic es software GPL-3.0; su código upstream y el parche de este proyecto se documentan en `third_party/boomingmusic/`.

Android y Motorola son marcas de sus respectivos titulares. Este proyecto no está afiliado a Motorola Mobility LLC.
